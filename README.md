# 정보이용탐색
-비슷한 문제에 대한 이전 경험이나 지식을 바탕으로 어떤 기준을 판단하여 결정하는 탐색방법
-만들어진 정보를 휴리스틱 정보라하여 휴리스틱 탐색이라고도 함
-문제의 해가 정확히 나오지 않을 때,정해진 시간 안에 모든 탐색을 완료하지 못할 때 유용(효율적이지X)
-방법은 여러가지
-
# 언덕 등반 탐색(HCS)
-경험적 탐색 방법의 하나
-경험에 의한 평가 함숫값이 가장 좋은 주변 지점을 하나씩 선택해서 확장해 나가는 탐색방법
-그리디 알고리즘(greedy algorithm) 이라고도 함
-지역적으로도 최적의 해, 전체적으로 최적의 해를 찾는 문제에 적합
-
# 최상우선탐색 (BFS: best first search)
-최적 우선 탐색 또는 최고 우선 탐색
- 언덕 등반 탐색을 개선한 탐색 알고리즘, 알고리즘으로 평가함수 &open,close리스트를 사용해 리스트 안에 있는 요소 중 가장 유리한 것을 선택
- 최상 우선 탐색은 선택되지 못한 노드도 다시 고려하는 과정을 거침
